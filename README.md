# Анализ труда мигрантов (ИТМ-2019)

Учебный проект по статистическому анализу продолжительности рабочей недели на основе данных Росстата.

## Данные

Источник — [Выборочное наблюдение труда мигрантов, 2019](https://rosstat.gov.ru/free_doc/new_site/imigr18/index.html), раздел «Миграционный статус». В исходном CSV 308 099 строк и 52 столбца. Для анализа отобраны записи с `RBVR_FOS > 0` — **160 023 наблюдения**.

## Что сделано

- Описательная статистика возраста, состава домохозяйства и продолжительности рабочей недели.
- Гистограммы и диаграммы размаха (box plot).
- Сравнение групп по возрасту, образованию, миграционному и социальному статусу, федеральному округу.
- Корреляционное отношение и доля межгрупповой вариации (η²).
- Сравнение показателей по месяцам опроса.

**Инструменты:** Python, pandas, NumPy, Matplotlib, SciPy, Jupyter Notebook.

## Результаты

| Показатель | Значение |
|---|---:|
| Средняя продолжительность рабочей недели | 38,88 ч |
| Международные мигранты | 39,53 ч |
| Остальные респонденты | 38,85 ч |
| Разница средних | 0,68 ч |
| η² для миграционного статуса | 0,034% |
| η² для социального статуса | 8,86% |

Различия между группами описывают связи в данных, но не доказывают причинного влияния. Расчёты сделаны без выборочных весов.

## Файлы и запуск

- `Solving_ITM_2019.ipynb` — код, таблицы и графики.
- `data/itm_2019.csv` — исходные данные.
- `Original_report.docx` — отчёт по исследованию.

```bash
pip install -r requirements.txt
jupyter notebook Solving_ITM_2019.ipynb
```

Ноутбук оформлен по материалам исследования и позволяет повторить приведённые расчёты на исходных данных.
